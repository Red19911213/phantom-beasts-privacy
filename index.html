一、我们处理哪些信息

本地游戏进度与设置。伙伴、编队、背包、金币、远征进度，以及音量、画面设置保存在本机应用存储中，用于继续游戏和保留你的选择。游戏目前没有开发者运营的云存档服务，也不会将这些游戏进度主动上传给开发者。清除应用数据或卸载可能导致进度丢失。

登录与实名认证。同意本政策后，游戏调用 TapTap 登录和合规认证服务。登录仅请求基础账号信息（openId、unionId）；使用 openId 区分认证账号，不请求好友、头像或昵称权限。实名认证由 TapTap 提供，你的实名信息在其认证界面提交或授权。游戏不自行制作身份证收集表，也不将姓名或身份证号码写入本地游戏存档。游戏使用认证结果判断是否可以进入、继续游戏。

必要的设备及网络信息。TapSDK 在提供登录、合规认证及安全运行服务时，会按其规则处理系统版本、设备型号、CPU 信息、网络类型、Android ID、设备内存信息，以及识别 TapTap 客户端所需的指定应用信息；联网请求还会包含 IP 地址等通信信息。各模块的具体范围、用途和频次见下方官方说明。此版本关闭可选的 TapTap 事件分析、自动设备登录事件和 OAID 反射获取，不接入支付或通讯录功能。广告测试版本还包含下述可选的激励广告服务。

自愿观看的广告。配置了广告服务的 Android 版本可在捕获盒用完或队伍战败时，由你选择观看广告领取奖励。每趟分别限一次。不观看不会扣除金币；放弃复活按原有战败规则结算。只有广告服务确认奖励后才发放，单纯关闭或播放结束不算确认。广告请求和奖励领取状态保存在本机，用于避免重复领取及恢复中断的领取流程。

你主动发来的反馈。通过邮件联系时，我们会收到你的邮箱地址及邮件内容，用于回复、排查问题和处理个人信息请求。请不要发送密码、验证码、身份证照片或其他与问题无关的敏感资料。

二、权限与使用时机

  • 网络访问、网络状态：用于连接 TapTap 登录、认证及你主动选择的广告服务，不是摄像头、麦克风或定位授权。
  • 本版本不主动申请定位、通讯录、相机、麦克风、相册或外部存储读取权限。
  • 首次启动会先显示隐私说明及同意选项，不预先勾选。只有同意后才调用 TapSDK 业务初始化、登录和认证。
  • 认证取消、网络错误、可玩时段或时长受限时，不会把未认证状态当作通过。

三、第三方 SDK 清单

TapSDK（TapTap 登录、合规认证及必要基础模块）
提供者：易玩（上海）网络科技有限公司。使用目的：账号登录、实名认证、防沉迷及服务安全运行。处理方式：SDK 在本机按功能需要采集，并向服务提供者传输必要信息；身份信息由其认证服务处理。我们取得必要账号标识和认证结果，不经营独立实名信息库。

信息类型包括基础账号标识、实名认证所需信息，以及第一节列明的必要设备和网络信息。详情请阅读 TapSDK 隐私政策和TapSDK 合规使用说明。本游戏未接入的其他 TapSDK 功能不因文档列举而自动启用。

TapADN SDK 5.3.3.0（激励视频广告）
提供者：上海艾得蒽数字科技有限公司。用途：提供自愿观看的广告、验证奖励、统计广告效果及防作弊。仅在你同意本政策、通过登录与合规认证，并点击“看广告”后初始化和请求广告。SDK 会处理设备品牌、型号、系统版本、屏幕与语言信息、CPU、可用存储空间、网络通信信息（包括 IP 地址）、应用包名与版本、前后台及进程信息、广告展示和交互记录、崩溃及性能数据，并向服务提供者传输。本游戏关闭个性化广告、摇一摇、位置、电话状态、Wi-Fi 详细信息、传感器、OAID、Android ID、应用列表及外部存储读取开关，不申请安装应用权限。具体处理规则和权利渠道见 TapADN SDK 隐私政策及合规使用说明。无需观看广告即可继续正常游戏；未配置广告服务的版本不会启动该 SDK。

本页面没有广告、统计脚本或第三方追踪代码。网页通过 GitHub Pages 提供，托管服务可能为交付页面和保障安全处理访问日志；其处理规则见 GitHub 隐私声明。应用内也附带本政策正文，可以离线阅读；主动打开外部链接时由对应网站处理请求。

四、存储、共享与安全

游戏进度与设置保存在当前设备，应用关闭系统自动备份选项；不同 TapTap 账号不会自动生成不同的本地存档，也不会同步或覆盖其他设备进度。TapTap 登录缓存和认证数据的保存位置、期限及权利处理适用其隐私政策。我们收到的反馈邮件只在处理问题、履行法定义务或解决争议所需期间保留，目的完成后删除或匿名化处理。

我们不出售个人信息，不将本地游戏进度用于广告定向。除实现上述必要服务、你明确授权或法律要求外，不主动向其他机构共享你的信息。我们限制可访问反馈信息的范围，避免在游戏日志中输出实名资料和账号凭证；但任何技术措施都无法保证绝对安全。

五、你的选择与权利

  • 不同意：可在首次说明页选择退出，不启动登录或认证流程。
  • 再次查看：小岛“设置”中的“隐私政策与个人信息说明”可随时打开本政策。
  • 撤回同意：在设置中的隐私政策页选择“撤回同意并退出游戏”，或在认证入口选择“撤回同意并退出”。这会清除本游戏保存的同意记录及 TapTap 本地登录状态，结束本次游戏，不删除游戏进度。下次启动重新征求同意。撤回不影响撤回前依法开展的处理。
  • 删除本地进度：可使用 Android 系统的应用存储“清除数据”功能。此操作不可撤销，请先确认不再需要存档。退出游戏或撤回同意不等于删除进度。
  • 访问、更正、删除及其他请求：请邮件联系 fcy1213@qq.com，说明请求和必要的身份核实线索。我们将在法律要求的期限内核实并处理。TapTap 账号或其直接处理的信息，可通过 TapTap 的账号设置、隐私渠道办理；本游戏不会注销你的整个 TapTap 账号。

六、未成年人保护

未满14周岁的用户，应请监护人阅读本政策并确认后使用。我们通过 TapTap 合规认证结果执行游戏时间与时长限制，不以自填年龄代替实名认证。当前版本没有充值服务。监护人如认为我们不当处理了未成年人信息，可通过联系邮箱提出核查、纠正或删除请求。游戏的适龄提示与实名认证结果是不同事项，适龄提示不代表可以绕过防沉迷规则。

七、政策更新

接入新的 SDK、广告或支付等功能，或对信息用途作出重要变更前，我们会更新本政策，并按需要重新取得同意。你可根据页面上的日期和政策版本核对变化。
